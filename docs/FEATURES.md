# Notepad++ feature map

Every command in Notepad++'s menus, taken from its own menu resource, and where Pocketpad++ stands on it.
Generated by `tools/feature_map.py`; edit the rules there, not this file.

| Status | Meaning | Commands |
|---|---|---|
| Done | Implemented in the current build | 214 |
| Engine | Scintilla already does it; needs a menu entry or gesture | 38 |
| Build | Application feature to write | 192 |
| Adapt | Carries over, but needs an Android-specific design | 26 |
| No | Tied to Windows; not portable | 11 |
| | Total | 481 |

Of the 214 implemented commands, 94 are entries of the Language menu and 56 are encodings; 64 are editing, file, search and view commands.
Implemented means built and, where it is logic rather than screen layout, covered by the desktop tests.
It does not yet mean checked by hand on a range of devices.

## Phases

| Phase | Scope | Done | Remaining |
|---|---|---|---|
| 1 | Core editor: tabs, files, encodings, languages, find and replace, sessions | 214 | 0 |
| 2 | Editing power tools: remaining line, case, blank and selection commands, multi-select, column mode, recent files | 0 | 118 |
| 3 | Search power tools: find in files, mark, styled tokens, incremental search, results panel | 0 | 48 |
| 4 | Panels and views: document list, function list, document map, folder as workspace, split view, auto-completion | 0 | 54 |
| 5 | Customisation: preferences, style configurator and themes, shortcut mapper, user-defined languages | 0 | 15 |
| 6 | Macros, run, tools, printing | 0 | 20 |

Not counted above because they are not menu commands: the plugin system (Notepad++ plugins are
Windows DLLs and cannot be loaded; an extension mechanism of our own would be a separate project),
and behaviour that lives in Preferences such as auto-completion settings, backup intervals and
the many editing options, which phase 5 will inventory separately.

Regular expressions currently use the C++ standard library's ECMAScript syntax; Notepad++ uses
Boost.Regex (Perl syntax, including lookbehind and `\K`). Matching that is a phase 3 item.
